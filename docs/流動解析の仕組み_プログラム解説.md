本ツールは **Python** で書かれており、次のライブラリ／フレームワークを使っています。

- **数値計算** — numpy（配列演算）と scipy（疎行列ソルバー）
- **画面表示** — Streamlit（Webアプリのフレームワーク）

用語解説

- **配列演算** — 多数のマス目に並べた数値へ、1マスずつ順にではなく表ごと一括で計算をかける仕組みです。これを numpy が担います。
- **疎行列ソルバー** — ほとんどの要素がゼロになる巨大な連立方程式（＝疎行列）を、ゼロでない部分だけを使って効率よく解くプログラムです。scipy の `spsolve` がこれにあたります。

やっていることを一言でいえば、**製品形状を細かい格子（マス目）に分け、隣り合うマスの関係を一つの巨大な連立一次方程式にまとめて一度だけ解く**、これだけです。

処理は次の順序で流れます。

1. **形状を格子に落とす**

   製品の形を多数のマス目に区切り、各マスにその場所の肉厚 $h$ を持たせます。

2. **粘度を決める**

   樹脂温度と金型温度の代表値（加重平均）と、代表的な剪断速度から Cross-WLF 式で粘度 $\eta$ を一度だけ計算します。

3. **流動性を配列で求める**

   各マスで $S = h^3 / (12\eta)$ を計算します。これが「そのマスの流動性」です。

4. **連立方程式に組む**

   隣り合うマス同士の関係（上下左右の4方向）を、要素のほとんどがゼロの巨大な行列（疎行列）として組み立てます。マスの境目の流動性は両側の値の調和平均を取り、ゲートには「到達時間ゼロ」、外壁には「樹脂が漏れない」という条件を入れます。

5. **一発で解く**

   scipy の疎行列ソルバー（`spsolve`）に渡し、全マスの「到達しやすさ $\tau$」を一度に求めます。商用CAEが時間を細かく刻んで樹脂先端を少しずつ進めるのに対し、本ツールはこの地図を1回解くだけで充填の概形を得ます。

6. **結果に変換する**

   $\tau$ を充填時間と圧力分布に換算し、流れが合流する場所（ウェルドライン）や最後に充填される場所（エアトラップ）を $\tau$ の形から拾い出します。

骨格をコードで示すと、おおよそ次の通りです。

```python
import numpy as np
import scipy.sparse as sp
import scipy.sparse.linalg as spla

# 1. 形状を格子に：各マスにその場所の肉厚 h を持たせる
h = geometry.thickness_mm * 1e-3                 # [m]

# 2. 粘度を1回だけ評価（樹脂温度と金型温度の代表値・代表剪断速度から Cross-WLF）
eta = cross_wlf_viscosity(material, T_bulk, gamma_dot)

# 3. 各マスの「流動性」 S = h^3 / (12 eta)
S = h**3 / (12.0 * eta)

# 4. 隣り合うマスの関係を巨大な疎行列 A に組む（5点ステンシル）
A = sp.lil_matrix((N, N))
b = np.ones(N)
for k, cell in enumerate(cavity_cells):
    if cell in gates:                            # 境界条件：ゲートは tau = 0
        A[k, k] = 1.0; b[k] = 0.0
        continue
    for neighbor in (up, down, left, right):     # 上下左右の4方向
        S_face = 2*S_c*S_n / (S_c + S_n)         # 境目は調和平均
        coeff  = S_face / dx**2
        A[k, neighbor] -= coeff
        A[k, k]        += coeff                  # 外壁方向は何もしない＝漏れなし

# 5. tau（到達しやすさの地図）を一発で解く
tau = spla.spsolve(A.tocsr(), b)

# 6. 後処理：充填時間・圧力に換算、ウェルド／エアトラップを抽出
fill_time = tau / tau.max() * T_fill
pressure  = 1.0 - tau / tau.max()
```
