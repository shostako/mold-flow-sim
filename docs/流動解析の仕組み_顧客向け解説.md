本ツールは、対象を**薄肉の導光板（極薄プレート）に絞ることで成り立つ**簡易計算を行います。絶対値を当てる道具ではなく、**設計案同士を素早く見比べて当たりをつける**もので、商用CAE（Moldflow等）の代替ではありません。

## 1. 計算の核心

樹脂の**各地点への「到達しやすさ」を表す地図を解きます**。この地図そのものは一度に解けます（時間を刻んで先端を進める計算をしません）。ただし後述の壁面冷却モデルを使う場合は、温度や流路の狭まりを反映しながらこの地図を数回解き直します。この地図は数学的に**定常状態の熱伝導と同じ形（ポアソン方程式）**になります。ゲートを起点に地図を描くと、その等高線が充填の進行を表します。

この計算は、商用CAEの標準的なフロント追跡解析（圧力や流動速度の分布を時々刻々と解き直して樹脂先端を進める時間発展計算）を**時間を刻まずに済ませた簡略版**です。壁面冷却モデルで数回解き直す場合も、繰り返しているのは同じ地図の解き直しであって、樹脂先端を時間発展させているわけではありません。流路が単純なら本格的な解析に近い結果が出ますが、形が複雑になるほどズレは大きくなります。

地図は次の **3つの物理モデル** を組み込んで解いています。

**① 流路の流動性（Hele-Shaw 近似｜薄肉流動の古典理論）**

$$S = \frac{h^{3}}{12\,\eta}$$

ここで $h$＝肉厚、$\eta$＝粘度、$S$＝流動性。肉厚 $h$ が **3乗で効く** のが肝で、肉厚が半分なら流動性は $1/8$ に激減します。「薄い所ほど急に流れにくい」という実機の感覚をこの一式で表現しています。バランサー（肉盗み）が効くのもこの原理です。

**② 樹脂の粘度（Cross-WLF モデル｜業界標準）**

$$\eta = \frac{\eta_{0}}{1 + \left(\dfrac{\eta_{0}\,\dot{\gamma}}{\tau^{*}}\right)^{1-n}}
\qquad
\eta_{0}(T) = D_{1}\,\exp\!\left(\frac{-A_{1}\,(T-T^{*})}{A_{2} + (T-T^{*})}\right)$$

粘度は一定ではなく、**高温ほど・剪断が強いほどサラサラ**になる性質を表します（$\dot{\gamma}$＝剪断速度、$T$＝温度〔樹脂温度と金型温度の加重平均〕、$n,\ \tau^{*},\ D_{1},\ A_{1},\ A_{2}$＝樹脂ごとの係数）。PP・ABS・PC など8種を内蔵しています。

**③ 充填の順番（地図の方程式）**

$$\nabla\!\cdot\!\left(S\,\nabla\tau\right) = -1 \quad(\text{キャビティ内部})$$

$$\tau = 0 \ \ (\text{ゲート}) \qquad S\,\nabla\tau\cdot\mathbf{n} = 0 \ \ (\text{壁})$$

通りやすさ $S$ に応じて到達地図 $\tau$ が広がること、ゲートが起点であること、壁から漏れないことを表します。$\tau$ を換算すると各地点の充填時間になります。

## 2. 向き不向き

| ✅ 向いている | ❌ 向かない・非対応 |
|--------|------------------|
| 設計案の相対比較 | 充填時間・圧力の絶対値の保証 |
| ゲート／肉厚／バランサーの当たり付け | 角部の渦・二次流・ジェッティング（2D近似のため原理的に捕捉不可） |
| 多数案を高速に試行 | 保圧・収縮・反り・結晶化 |
| 肉厚差が流れに効く様子の把握（薄い所ほど流れにくい） | 流速から粘度へのフィードバック（後述の層別モードは温度経由で粘度を反復更新するが、流速→粘度の環は繋いでいない） |

## 3. オプションの壁面冷却モデル

上の①〜③に加えて、金型に触れた樹脂が冷えて固まっていく効果を、次の2通りで取り込めます。**極薄プレートでは肉厚に対して固化層の割合が大きく、無視すると流れを楽観しすぎる**ため、既定では「層別」を選んでいます。

- **スキン層（1層）** — 壁で固まった層の厚みぶん流路を細くして解き直す。表層固化とショートショットの予測がここから出ます
- **層別（N層）** — 厚み方向を複数の層に分け、**層ごとに温度と粘度を計算し直して**解き直す。厚み方向の温度／粘度分布と、剪断発熱による温度上昇まで扱います

どちらも計算は実装済みで、動きます。ただし**精度は保証できません**。物理モデルは大きく簡略化してあり（壁からの熱伝導は1次元の解析解、粘度に返しているのは温度だけで流速からの環は繋いでいない、面内の3次元流れは扱わない）、何より**実機の成形結果と照合した較正を行っていません**。

したがってこれらのオプションは、**「固化を考慮すると傾向がどちらへ動くか」を見るためのもの**とお考えください。数値そのものを設計判断の根拠にできる段階ではありません。この点は本ツール全体の位置づけ（絶対値ではなく案同士の相対比較）と同じで、オプションを使ってもその性格は変わりません。
