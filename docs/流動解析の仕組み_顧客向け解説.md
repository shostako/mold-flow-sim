本ツールは、対象を**薄肉の導光板（極薄プレート）に絞ることで成り立つ**簡易計算を行います。絶対値を当てる道具ではなく、**設計案同士を素早く見比べて当たりをつける**もので、商用CAE（Moldflow等）の代替ではありません。

## 1. 計算の核心

樹脂の**各地点への「到達しやすさ」を表す地図を1回の計算で解きます**。この地図は数学的に**定常状態の熱伝導と同じ形（ポアソン方程式）**になります。ゲートを起点に地図を描くと、その等高線が充填の進行を表します。

この計算は、商用CAEの標準的なフロント追跡解析（圧力や流動速度の分布を時々刻々と解き直して樹脂先端を進める時間発展計算）を**一度の計算で済ませた簡略版**です。流路が単純なら本格的な解析に近い結果が出ますが、形が複雑になるほどズレは大きくなります。

地図は次の **3つの物理モデル** を組み込んで解いています。

**① 流路の流動性（Hele-Shaw 近似｜薄肉流動の古典理論）**

$$S = \frac{h^{3}}{12\,\eta}$$

ここで $h$＝肉厚、$\eta$＝粘度、$S$＝流動性。肉厚 $h$ が **3乗で効く** のが肝で、肉厚が半分なら流動性は $1/8$ に激減します。「薄い所ほど急に流れにくい」という実機の感覚をこの一式で表現しています。バランサー（肉盗み）が効くのもこの原理です。

**② 樹脂の粘度（Cross-WLF モデル｜業界標準）**

$$\eta = \frac{\eta_{0}}{1 + \left(\dfrac{\eta_{0}\,\dot{\gamma}}{\tau^{*}}\right)^{1-n}}
\qquad
\eta_{0}(T) = D_{1}\,\exp\!\left(\frac{-A_{1}\,(T-T^{*})}{A_{2} + (T-T^{*})}\right)$$

粘度は一定ではなく、**高温ほど・剪断が強いほどサラサラ**になる性質を表します（$\dot{\gamma}$＝剪断速度、$T$＝温度〔樹脂温度と金型温度の加重平均〕、$n,\ \tau^{*},\ D_{1},\ A_{1},\ A_{2}$＝樹脂ごとの係数）。PP・ABS・PC など8種を内蔵しています。

**③ 充填の順番（地図の方程式）**

$$\nabla\!\cdot\!\left(S\,\nabla\tau\right) = -1 \quad(\text{キャビティ内部})$$

$$\tau = 0 \ \ (\text{ゲート}) \qquad S\,\nabla\tau\cdot\mathbf{n} = 0 \ \ (\text{壁})$$

通りやすさ $S$ に応じて到達地図 $\tau$ が広がること、ゲートが起点であること、壁から漏れないことを表します。$\tau$ を換算すると各地点の充填時間になります。

## 2. 読み取れる結果

| 出力 | 内容 |
|------|------|
| 充填時間 | どこが先／最後に充填されるか |
| 圧力分布 | ゲート付近が高く末端で低い |
| ウェルドライン | 流れの合流箇所（推定） |
| エアトラップ | 最後に充填される＝空気が残る箇所（推定） |

ウェルドライン／エアトラップは、厳密な界面追跡ではなく地図の形状パターンからの推定です。

オプションで以下の物理現象：

- 表層固化（スキン層）
- ショートショット
- 厚み方向の温度／粘度分布
- 剪断発熱

も選択出来るようになっていますが、いずれも物理モデルを大きく簡略化した段階で、モデルの取り込みもコードへの反映もまだ途上です。設計案同士の相対的な傾向をつかむのも、現状では参考程度にもならない状況です。プログラムの改造は停滞中です。

## 3. 向き不向き

| ✅ 向いている | ❌ 向かない・非対応 |
|--------|------------------|
| 設計案の相対比較 | 充填時間・圧力の絶対値の保証 |
| ゲート／肉厚／バランサーの当たり付け | 角部の渦・二次流・ジェッティング（2D近似のため原理的に捕捉不可） |
| 多数案を高速に試行 | 保圧・収縮・反り・結晶化 |
| 肉厚差が流れに効く様子の把握（薄い所ほど流れにくい） | 流動中の局所的な粘度更新（代表値で1回評価） |
