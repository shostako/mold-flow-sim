# 流動解析ツールの仕組み（ご説明資料）

本資料は、射出成形の流動をどう計算しているかを簡潔にまとめたものです。

> **ひとことで**: 本ツールは、対象を**薄肉の導光板（極薄プレート）に絞ることで成り立つ**簡易計算です。絶対値を当てる道具ではなく、**設計案どうしを素早く見比べて当たりをつける**もので、商用CAE（Moldflow等）の代替ではありません。

## 1. 計算の核心

樹脂が**各地点へ届く「届きやすさ」の地図を1回の計算で解きます**。この地図は数学的に**熱伝導と同じ形（拡散方程式）**になります。ゲートを起点に地図を描くと、その等高線が充填の進む様子になります。

この計算は、商用CAEの標準的なフロント追跡解析（物理場を時々刻々と解き直して樹脂先端を進める時間発展計算）を**一度の計算で済ませた簡略版**です。確立された標準手法ではなく独自の高速近似で、単純な流路ではよく一致し、複雑形状ほど差が出ます。

地図は次の **3つの物理** を組み込んで解いています。

**① 流路の通りやすさ（Hele-Shaw 近似）**

$$S = \frac{h^{3}}{12\,\eta}$$

ここで $h$＝肉厚、$\eta$＝粘度、$S$＝通りやすさ。肉厚 $h$ が **3乗で効く** のが肝で、肉厚が半分なら通りやすさは $1/8$ に激減します。「薄い所ほど急に流れにくい」という実機の感覚を一行で押さえています。バランサー（肉盗み）が効くのもこの原理です。

**② 樹脂の粘り（Cross-WLF モデル｜業界標準）**

$$\eta = \frac{\eta_{0}}{1 + \left(\dfrac{\eta_{0}\,\dot{\gamma}}{\tau^{*}}\right)^{1-n}}
\qquad
\eta_{0}(T) = D_{1}\,\exp\!\left(\frac{-A_{1}\,(T-T^{*})}{A_{2} + (T-T^{*})}\right)$$

粘度は一定ではなく、**高温ほど・剪断が強いほどサラサラ**になる性質を表します（$\dot{\gamma}$＝剪断速度、$T$＝樹脂温度、$n,\ \tau^{*},\ D_{1},\ A_{1},\ A_{2}$＝樹脂ごとの係数）。PP・ABS・PC など8種を内蔵していますが、**ジェネリック値**のため実検討では実測データへの差し替えが前提です。

**③ 充填の順番（地図の方程式）**

$$\nabla\!\cdot\!\left(S\,\nabla\tau\right) = -1 \quad(\text{キャビティ内部})$$

$$\tau = 0 \ \ (\text{ゲート}) \qquad S\,\nabla\tau\cdot\mathbf{n} = 0 \ \ (\text{壁})$$

通りやすさ $S$ に応じて到達地図 $\tau$ が広がる・ゲートが起点・壁から漏れない、という意味です。$\tau$ を換算すると各地点の充填時間になります。

## 2. 読み取れる結果

| 出力 | 内容 |
|------|------|
| 充填時間 | どこが先／最後に埋まるか |
| 圧力分布 | ゲート付近が高く末端で低い |
| ウェルドライン | 流れの合流箇所（推定） |
| エアトラップ | 最後に埋まる＝空気が残る箇所（推定） |

オプションで表層固化（スキン層）・短ショット・厚み方向の温度／粘度分布・剪断発熱も近似的に扱えます（ウェルド／エアトラップは厳密な界面追跡ではなく地図形状からの推定）。

## 3. 得意と不得意

| ✅ 得意 | ❌ 不得意・非対応 |
|--------|------------------|
| 設計案の相対比較 | 充填時間・圧力の絶対値の保証 |
| ゲート／肉厚／バランサーの当たり付け | 角部の渦・二次流・ジェッティング（2D近似のため原理的に不可） |
| 多数案を高速に試行 | 保圧・収縮・反り・結晶化 |
| 薄板の本質（$h^{3}$ と粘度変化）を反映 | 流動中の粘度の局所追従（代表値で1回評価） |
