### Codex レビュー対応（P2、本物のバグ）

蘭（Codex）が PR でテーパ段化 OFF の左右非対称を指摘。最初の OFF 実装 `gate_left_offset = Wp - gate_position - 1` は **gate_position=0 専用の発想**で、gate_position>0（中央・左寄りゲート）だと x_2nd が中央に来て右側がハードコード5mmの2段テーパ、左側がuserの taper1_len になり「全幅単一テーパ」が破れていた。

**修正:** OFFでは `gate_left_offset=0`（has_2nd を全幅 True）＋`taper2_left=taper2_right=land_width`（far2=ランド端一定で2段目ランプ in2 を空に潰す）＋`mid_b=land_depth`（残る in1 が land_depth→mid_a の単一ランプ長さL1を全幅均一に描く）。far2 一定なので gate_position 非依存、far_max=land_width なので validate の extent 膨張もなし。

geometry の事実: `gate_left_offset` は mask を trim しない（`in_gate` は `xx>=pad` 全幅）。has_2nd（深さ境界）だけに効く。geometry.py の該当コメント「trim everything left of it」は実装と食い違う古い注記。

ユーザー要望でStreamlitのアクセント色をオレンジ系（デフォルト #FF4B4B）から変えたい件。14色相を実ウィジェットに当てた実物比較（軽量プレビューapp×別ポート起動→ヘッドレスChromeでスクショ→PIL合成）を見せてアンバー #F59F00 を採用、`.streamlit/config.toml` の `[theme]` に投入（PR #37 マージ）。

## 2026-06-08 作業概要

### 3D表示のカクカク（階段状）改善 = 表示専用supersample（PR #39、9ラウンドCodex対応）
ユーザーが3D表示の斜め境界が階段状になるのを改善したい件。原因は解析グリッド解像度（cell_size 0.5mm）がそのまま3Dの天面Surface境界・側壁Mesh3dに焼き付くこと。**表示専用に**メッシュを補間アップサンプリングする `supersample` 機能を `visualizer_3d.py` に追加（solver・geometry・解析時間は不変）。UIは3D expander内のスライダー「描画の細かさ」(1〜3、既定1)。

**Codexが9ラウンド連続でP指摘**。前半は実バグを正当に修正（回帰テスト付き）:
1. ゲート原点が偶数kでズレる → ゲートcellをk×kブロック展開で平均重心を厳密一致（P2）
2. `zoom` の grid_mode → `grid_mode=True` でセル全幅整合（P2、値ズレ）
3. 既定2が畳んだ3Dも毎rerunフル生成で重い → 既定1に（P2、Streamlitは畳んだexpander/非選択タブも実行する事実も判明）
4. ゲートの圧力値が補間で薄まる → ゲートブロックにrestamp（P2、圧力「1 at gate」）
5. 不連続キャビティ間の色にじみ → 連結成分別処理（P2）
6. 成分別処理の性能 → bbox + find_objects（P2、2段階）
7. 補間方式を **normalized convolution** に一新（`zoom(np.where(m,field,0))/zoom(m)`）で隙間非跨ぎ・成分内スロット・性能を一掃
8. 外殻NaN（fill_time/pressure）が `NaN·0=NaN` で側壁色を消す → `np.where` サニタイズ（**P1**、私のnormalized conv書き換えで作り込んだ本物の回帰をCodexが捕捉）
9. 斜め接触キャビティ混合 → **4連結成分ごとのnormalized convolution**（solverの4連結と整合）で完全版に

最後（9件目内の連結成分内斜めピンチ）は **bilinearの2×2カーネルが斜め隣接2セルを必ず混ぜる本質的限界**と見切り、CLAUDE.mdに「既知の制限」として明記してマージ（画像アップロード×斜めピンチ×supersample>1限定、パラメトリック形状・既定k=1は無影響）。`test_visualizer_3d.py` 8→25件、全体232テスト。学びはメモリ `feedback_adversarial_review_fundamental_limit.md`。
