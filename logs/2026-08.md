#### 実装（`core/profile_gate.py` 新設 696行）

geometry.py が既に1339行 + JSON I/O は異質な関心事なので**別モジュール**にした
（`from .geometry import Geometry` でコンテナだけ借り、builder の12ステップ定型は完全踏襲）。

- **`GateProfileSpec`**: JSON構造を鏡写しにした**ネスト frozen dataclass**（既存Configは全部
  フラットだが、それはスライダーUI駆動だから。JSON駆動なら round-trip・エラーメッセージ・
  省略可能セクションの全てでネストが有利）。`from_dict/from_json/from_json_file/to_dict/
  to_json/validate/t_max/ramp_cap_t`。エラーは `"island.boundary_line"` 形式のパス付き、
  **未知キーは拒否**（実寸JSONのタイポ検出）。
- **`ProfilePlateConfig`**: スペック（図面由来・不変）とプレート（UIで振る）は寿命が違うので分離。
- **`build_profile_gate_geometry(spec, plate, cell_size_mm)`**: 全numpyベクトル化。
  - ランド/メインランプ(cap底打ち)/アイランド/外壁線/井戸/バルブの合成
  - **井戸だけ距離場**（60°壁が体積に効くので `d_well = clip((hw−dist)·tanθ, 0, depth)`、
    `d = max(d, d_well)`）。アイランドの急壁はセル解像度1mm前提でシャープカット近似
  - `mask = in_gate_base | in_well | in_plate` の **OR が必須**（実寸案では井戸が外壁を突き抜ける）
  - 外壁線の t<始点側は全幅クランプ（外挿するとランド帯が狭まる罠）
  - `compression_mask = in_plate & mask`、ゲート土手、gates空時の最寄りセルスナップ防御
- UI（app.py）: デモプリセット/JSONアップロード/JSON貼り付けの3択 + プレートパラメータ
- CLI（run_demo.py）: `ProfileGate_demo` ケース
